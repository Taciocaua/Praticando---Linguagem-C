# Praticando Linguagem C

Repositório criado para registrar minha jornada de aprendizado e prática com a linguagem **C**.

Aqui estão reunidos exercícios e atividades desenvolvidos durante meus estudos, com foco no desenvolvimento da **lógica de programação** e na compreensão dos fundamentos da linguagem.

## Objetivo

O principal objetivo deste repositório é praticar e consolidar conceitos fundamentais de programação utilizando C.

Durante os estudos, busco desenvolver:

* Raciocínio lógico
* Resolução de problemas
* Organização de código
* Pensamento algorítmico
* Fundamentos da programação

## Conteúdos praticados

Entre os principais conceitos estudados estão:

* Variáveis e tipos de dados
* Operadores
* Entrada e saída de dados
* Estruturas condicionais
* `if`, `else` e `switch`
* Estruturas de repetição
* `for`, `while` e `do while`
* Arrays
* Strings
* Funções
* Ponteiros
* Estruturas de dados
* Exercícios de lógica de programação

## Como executar

Para executar os programas em C, é necessário ter um compilador instalado, como o **GCC**.

Exemplo:

```bash
gcc programa.c -o programa
```

Depois:

```bash
./programa
```

No Windows:

```bash
programa.exe
```
